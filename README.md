# 🏭 Manufacturing Efficiency Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting manufacturing efficiency using Machine Learning techniques.

The system analyzes manufacturing machine parameters such as temperature, vibration, power consumption, production speed, network performance, maintenance score, and error rate to predict the efficiency status of machines.

A Streamlit dashboard is developed to provide an interactive interface for users to enter machine parameters and get efficiency predictions.

---

## 🎯 Objectives

- Predict manufacturing machine efficiency using Machine Learning.
- Analyze important manufacturing parameters affecting efficiency.
- Build an interactive Streamlit dashboard for real-time prediction.
- Support predictive maintenance and operational decision-making.

---

## 📂 Dataset

**Dataset Name:**

`Thales_Group_Manufacturing.csv`

The dataset contains manufacturing machine records with operational and sensor information.

### Features include:

- Machine ID
- Operation Mode
- Temperature
- Vibration
- Power Consumption
- Network Latency
- Packet Loss
- Quality Control Defect Rate
- Production Speed
- Predictive Maintenance Score
- Error Rate

---

## ⚙️ Data Processing

The following preprocessing steps were performed:

- Data cleaning
- Handling missing values
- Feature engineering
- Feature scaling
- Label encoding
- Model training and evaluation

### Additional Features Created:

- Energy Efficiency
- Error Output Ratio
- Network Reliability
- Sensor Stability

---

## 🤖 Machine Learning Models

The project uses Machine Learning algorithms to classify manufacturing efficiency.

Models considered:

- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

The best performing model was saved and used for prediction.
